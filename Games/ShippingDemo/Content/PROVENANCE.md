# Where Reactor Run's assets come from

Every model, sound and image here was generated by `Tools/GenerateDemoAssets.py`, using
the Python standard library only. Nothing was downloaded and no third-party sample is
used. The files and the script are dedicated to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

Running the script again writes the same bytes.

| File | Used by | What it is |
| --- | --- | --- |
| `Models/training-target.glb` | training | a red and white target plate |
| `Models/factory-crate.glb` | factory | a dark crate with an amber band |
| `Audio/training-chime.wav` | training | the chime when training starts |
| `Audio/factory-alarm.wav` | factory | the reactor alarm, looping |
| `Audio/shot.wav`, `reload.wav`, `hit.wav`, `hurt.wav`, `pickup.wav` | both | the sidearm, hits, being hurt, pickups and objectives |
| `UI/training-badge.png` | training | the HUD's level badge |
| `UI/factory-badge.png` | factory | the HUD's level badge |

The fonts are the engine's own (see the engine's licenses).
