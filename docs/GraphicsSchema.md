# Graphics settings schema

Generated by `player --graphics-schema docs/GraphicsSchema.md`.

Files start with `swgraphics 1`. One key/value per line; `#` starts a comment.
Unknown keys, duplicate keys, non-finite numbers and unsupported versions are errors.
Omitted keys inherit the preceding layer: project manifest, Config/Graphics.swgraphics,
user preferences, then command-line overrides. See [Graphics](Graphics.md).

Presets (low, medium, high, ultra) set the keys marked *preset* and keep the others.
*Applies* says how a change reaches the screen: `uniform` next frame; `targets` once new
images are made, the old ones freed after the frames using them finish. No setting needs a
restart, and none waits for the GPU to go idle except where noted in Graphics.md.

| Key | Values | Built-in default | Preset | Applies | Meaning |
|---|---|---|---|---|---|
| render_scale | 0.25..2 | 1 | preset | targets | Scene resolution as a multiple of the output. Below 1 is faster and softer; above 1 supersamples. Game UI always draws at output resolution. |
| shadow_quality | off, low, medium, high, ultra | high | preset | targets | Shadow map size and filtering. Off keeps direct lighting but draws no shadow maps. |
| anti_aliasing | none, fxaa, taa | none | preset | targets | Smooths jagged edges. FXAA is a fast pass after tone mapping. TAA jitters the camera and blends each frame with the last ones: steadier edges and fine detail, at the cost of some softness and ghosting on fast motion. Neither touches game UI, and they're never stacked. |
| bloom_quality | off, low, medium, high | high | preset | targets | How finely bloom is filtered: low starts at quarter resolution with 4 levels, medium at half with 5, high at half with 6. Off skips bloom and frees its memory. The scene's bloom intensity stays as authored. |
| bloom_scale | 0..1 | 1 |  | uniform | Your multiplier on each scene's bloom intensity: 1 is as the artist set it, 0 turns bloom off. |
| ambient_occlusion | off, low, medium, high | off | preset | targets | Darkens the light from the surroundings in creases, corners and under objects, worked out on the screen at half resolution: low takes 8 samples a pixel, medium 16, high 32. Direct light, shadows and glowing surfaces are unaffected. Off skips it and frees its memory. |
| baked_lighting | true, false | true |  | uniform | Light bounced around the scene, baked ahead of time into lightmaps and probe volumes. Off lights everything from the sky and environment alone. Costs one texture read a pixel; scenes without a bake look the same either way. |
| reflection_probes | true, false | true |  | uniform | Reflections captured inside rooms and corridors, blended over the sky's where a scene places reflection probes. Off reflects the sky and environment everywhere. Costs up to two cube reads a pixel; scenes without probes look the same either way. |
| decals_quality | off, low, medium, high | high | preset | targets | Marks projected onto surfaces: bullet holes, signs, grime. Low draws up to 64 a frame, medium 256, high 1024, the nearest first (gameplay markers before decoration). Off draws none and frees their memory; scenes without decals look the same either way. |
| light_culling | auto, clustered, brute_force | auto |  | uniform | How each pixel finds the point and spot lights that reach it. Clustered sorts lights into a grid of screen tiles and distances first, so each pixel tests only those near it; brute force tests every light everywhere. Auto clusters when a frame has 8 or more of them. The picture is the same either way: only the cost differs. |
| soft_particles | true, false | true | preset | uniform | Smoke, dust and glows fade out where they meet walls and floors, and as they reach the camera, instead of cutting a hard line through them. Effects choose how soft. Off draws the hard edges and saves a depth read a particle pixel. |
| particle_distortion | true, false | true | preset | targets | Effects that bend the scene behind them: heat above fire, shock waves. Off skips those parts of an effect, with no copy of the scene and no memory for it. |
| particle_lighting | simple, scene | scene | preset | uniform | How lit particles (smoke, dust) are lit. Scene lights them by every light, so a muzzle flash or a lamp lights the smoke around it; simple uses the sun and the ambient light alone, which costs less. |
| color_grading | true, false | true |  | uniform | The scene's colour look from its postprocess profiles: white balance and creative LUTs. Off shows the colours ungraded, exactly as without them. |
| auto_exposure | true, false | true |  | uniform | Lets scenes that ask for it adjust their brightness to what the camera sees, like an eye adapting. Off keeps each scene's fixed exposure, with no metering pass. |
| fog_quality | off, analytic, low, medium, high | medium | preset | targets | How scenes with fog draw it. Analytic is the cheap closed form, lit by the sun; low, medium and high add a volume near the camera lit by every lamp, with the sun's shadows, at coarser to finer detail. Off draws no fog, with no passes or memory for it. |
| lod_error_pixels | 0..100 | 1 | preset | uniform | How far, in rendered pixels, a simpler mesh level may differ from the full one. 0 always draws full detail. Needs imported levels of detail. |
| texture_quality | low, medium, high, ultra | ultra | preset | targets | How much of each material texture stays on the GPU: ultra keeps full size, high drops the largest mip level (a quarter of the memory), medium two, low three. UI textures always keep full size. |
| material_quality | low, high | high | preset | uniform | High draws every material layer. Low skips detail layers (the close-up micro texture some materials add) to save texture reads; base materials and second layers are unchanged. |
| anisotropy | 1, 2, 4, 8, 16 | 16 | preset | pipeline | Anisotropic filtering: the most samples a texture seen at a grazing angle may take. Higher keeps floors and roads sharp into the distance. Nearest-filtered (pixel art) textures are unaffected. |
| vsync | true, false | true |  | targets | Synchronize presentation with the display, so frames never tear. |
| frame_limit | 0 or 10..1000 | 0 |  | uniform | Frames per second at most; 0 means uncapped apart from VSync. |
| low_latency | true, false | false |  | uniform | Wait for each frame to reach the screen before reading input for the next, so input feels more immediate. Costs some frame rate when the GPU is the bottleneck. |
