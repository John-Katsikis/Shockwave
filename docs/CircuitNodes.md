# Circuit nodes

Generated by `player --node-schema docs/CircuitNodes.md`; don't edit by hand. [Circuits](Circuits.md) explains the file format and how circuits run.

Every node below is used as `node <name> <Id>`. Pins without a value use the default shown. Required pins must be connected or given a value; constant pins must be a literal.

Besides these, every circuit variable has two nodes: `Get.<variable>` (output `value`) and `Set.<variable>` (exec, input `value`, output `value`). The `Component.*` nodes are made from the components registered when this was written, the game's own included.
