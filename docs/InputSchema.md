# Input schema

Generated by `player --input-schema`; don't edit by hand.

A project's controls live in `Config/Input.swinput`, next to its `.swproject`. The editor
edits the same file (Window > Input) and reloads it when it changes on disk.
`player --check` validates it, and `player --devices` lists the controllers plugged in.

```
shockwave_input 1
deadzone 0.15                  # sticks and joystick axes read 0 below this
bind jump key Space
bind jump pad south            # Cross on PlayStation, A on Xbox
bind steer_right pad_axis left_x +
bind throttle joy "T.16000M" axis 2 full invert
bind brake joy "G29" axis 3 full
```

Each `bind` adds one input to an action; an action can have any number. An action named
in the file replaces the engine's built-in bindings for it. Game code reads actions, never
devices: `isActionDown`, `wasActionPressed`, `actionValue` (0..1) and `axis(neg, pos)` (-1..1).

## Inputs

| Form | Meaning |
|---|---|
| `key <name>` | a keyboard key, by position (WASD stays WASD on any layout) |
| `mouse <button>` | a mouse button |
| `pad <button>` | a button on any gamepad (PlayStation, Xbox, Switch, Steam...) |
| `pad_axis <axis> <range> [invert]` | a gamepad stick or trigger |
| `joy <device> button <n>` | a button on another controller: HOTAS, wheel, pedals, arcade stick |
| `joy <device> axis <n> <range> [invert]` | an axis on one |
| `joy <device> hat <n> <up/down/left/right>` | a hat switch direction |

`<device>` is part of the controller's name as `player --devices` prints it, in quotes if it
has spaces, or `*` for any. Joystick buttons and axes count from 0.

`<range>` picks the part of an axis that counts: `+` the half above center, `-` the half
below, `full` the whole travel as 0..1 (for pedals and throttles that rest at one end).
`invert` flips the axis first. Stick Y is positive up.

## Gamepad buttons

Buttons are named by position so one binding works on every pad. The PlayStation
and Xbox names (`cross`, `a`, `circle`, `b`, `square`, `x`, `triangle`, `y`, `l1`, `lb`, `r1`, `rb`,
`l3`, `r3`, `options`, `menu`, `share`, `create`, `view`) are accepted too and saved by position.

| Name | PlayStation | Xbox |
|---|---|---|
| `south` | Cross | A |
| `east` | Circle | B |
| `west` | Square | X |
| `north` | Triangle | Y |
| `back` | Share / Create | View |
| `guide` | PS | Xbox |
| `start` | Options | Menu |
| `left_stick` | L3 | Left stick click |
| `right_stick` | R3 | Right stick click |
| `left_shoulder` | L1 | LB |
| `right_shoulder` | R1 | RB |
| `dpad_up` | D-pad up | D-pad up |
| `dpad_down` | D-pad down | D-pad down |
| `dpad_left` | D-pad left | D-pad left |
| `dpad_right` | D-pad right | D-pad right |
| `misc` | Mute | Share |
| `touchpad` | Touchpad click | - |

## Gamepad axes

| Name | Range |
|---|---|
| `left_x` | -1..1 (left/down negative) |
| `left_y` | -1..1 (left/down negative) |
| `right_x` | -1..1 (left/down negative) |
| `right_y` | -1..1 (left/down negative) |
| `left_trigger` | 0..1 (use `+`) |
| `right_trigger` | 0..1 (use `+`) |
