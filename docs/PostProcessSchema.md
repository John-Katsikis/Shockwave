# Postprocess profile schema

Generated by `player --postprocess-schema`; edit Source/Runtime/Engine/Private/PostProcess.cpp, not this file.

A `.swpostprocess` file starts with `swpostprocess 1`, may name a `parent "other.swpostprocess"`, then gives any of these keys once each. Keys it doesn't give come from its parent, then from the scene and the defaults below, which change nothing. `#` starts a comment.

| Key | Group | Values | Default | Unit | What it does |
|---|---|---|---|---|---|
| `exposure` | exposure | -16 to 16 | 0 | stops | Manual exposure: +1 doubles the brightness, -1 halves it. The scene's Environment exposure by default. |
| `auto_exposure` | auto_exposure | true, false | false |  | Meters the scene and adapts exposure to it, within the limits below. Off keeps the manual exposure. |
| `auto_compensation` | auto_exposure | -8 to 8 | 0 | stops | Added to the metered exposure: above 0 brighter than metered. |
| `auto_min_ev` | auto_exposure | -16 to 16 | -8 | stops | The lowest exposure it may choose (for very bright scenes). |
| `auto_max_ev` | auto_exposure | -16 to 16 | 8 | stops | The highest exposure it may choose (for very dark scenes). |
| `auto_target_gray` | auto_exposure | 0.01 to 1 | 0.18 |  | The scene's metered average becomes this grey (linear). |
| `auto_low_percentile` | auto_exposure | 0 to 1 | 0.5 |  | The darkest share of the screen ignored by metering. |
| `auto_high_percentile` | auto_exposure | 0 to 1 | 0.95 |  | Metering ignores the screen past this share, brightest last: a muzzle flash or the sun doesn't darken it. |
| `auto_brighten_time` | auto_exposure | 0 to 60 | 2 | seconds | Time constant for raising exposure (going into the dark): about two thirds of the way there after it. |
| `auto_darken_time` | auto_exposure | 0 to 60 | 1 | seconds | Time constant for lowering exposure (going into bright light). |
| `auto_metering` | auto_exposure | average, center | average |  | Average weighs the whole screen; center weighs the middle most, the corners an eighth. |
| `auto_reset_on_cut` | auto_exposure | true, false | true |  | A camera cut jumps straight to the metered exposure instead of adapting. |
| `white_point` | white_balance | 2 numbers, 0.01 to 0.99 | 0.3127 0.329 | CIE xy | Illuminant white to neutralize: a surface lit by this white comes out neutral. D65 (0.3127 0.3290) changes nothing; incandescent light is about 0.4476 0.4074. |
| `lut` | lut | "path.cube" | none |  | A .cube 3D LUT (17, 33 or 65 entries a side) inside Content, applied after tone mapping. |
| `lut_encoding` | lut | srgb, linear | srgb |  | What the LUT's input and output are: sRGB-encoded (most grading tools) or display-linear. |
| `lut_intensity` | lut | 0 to 1 | 1 |  | How much of the graded colour is used: 0 none, 1 all of it. |
| `bloom_intensity` | bloom | 0 to 1 | 0.04 |  | Bright light spreading into its surroundings. The scene's Environment bloom by default. |
| `fog_density` | fog | 0 to 10 | 0 | 1/m | Extinction at fog_base_height: 0.01 hides things about 300 m away, 0.1 about 30 m. 0: no fog. |
| `fog_height_falloff` | fog | 0 to 10 | 0 | 1/m | How fast it thins with height: density falls to 1/e per 1/falloff metres up. 0: the same everywhere. |
| `fog_base_height` | fog | any | 0 | m | The height fog_density is measured at. |
| `fog_max_density` | fog | 0 to 10 | 1 | 1/m | The most it may reach anywhere, deep below the base height too. |
| `fog_color` | fog | 3 numbers, 0 to 1000 | 0.5 0.6 0.7 | linear | The light it scatters from the surroundings: thick fog fades to this colour. |
| `fog_albedo` | fog | 0 to 1 | 0.8 |  | How much of the sun's and lamps' light it scatters toward the camera: 0 only its own colour. |
| `fog_anisotropy` | fog | -0.9 to 0.9 | 0.3 |  | Henyey-Greenstein g: above 0 the fog glows looking toward a light, below 0 looking away. |
| `fog_start` | fog | 0 to 100000 | 0 | m | Clear air between the camera and where the fog begins. |
| `fog_sky_distance` | fog | 1 to 1000000 | 1000 | m | How far away the sky counts as. |
| `fog_volumetric_distance` | fog | 1 to 1000 | 64 | m | How far the lit fog volume reaches with fog_quality low, medium or high; the closed form past it. |

White points are checked as a whole (x > 0, y > 0, x + y < 1, at most 4x in any cone response); so are auto exposure (min below max, percentiles in order) and fog (no negative density, anisotropy within 0.9).
