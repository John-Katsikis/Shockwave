# Player preferences schema

Generated by `player --preferences-schema docs/PreferencesSchema.md`.

Files start with `swprefs 1`. One key and value per line; `#` starts a comment, and a
value with spaces is quoted. Unknown keys, duplicate keys, values out of range and NaN are
errors, with the line. Keys left out come from the layer below: the engine's defaults, the
project's `Config/Preferences.swprefs`, the player's own file, then `--pref key=value`. See
[Preferences](Preferences.md). Graphics preferences are in [GraphicsSchema](GraphicsSchema.md).

*Display* keys are kept within 15 seconds of a change, or put back.

| Key | Group | Values | Default | What it does |
|---|---|---|---|---|
| `window_mode` | Display *(display)* | windowed, borderless, fullscreen | `windowed` | Windowed, borderless (the whole display at its own resolution) or fullscreen (the display switches to the resolution) |
| `window_width` | Display *(display)* | 0, or 320..16384 | `0` | The window's width, or fullscreen's resolution; 0 for the game's own |
| `window_height` | Display *(display)* | 0, or 240..16384 | `0` | The window's height, or fullscreen's resolution; 0 for the game's own |
| `master_volume` | Audio | 0..1 | `1` | Everything the game plays |
| `effects_volume` | Audio | 0..1 | `1` | Sound effects, on top of the master volume |
| `music_volume` | Audio | 0..1 | `1` | Music, on top of the master volume |
| `ui_volume` | Audio | 0..1 | `1` | Menu and HUD sounds, on top of the master volume |
| `voice_volume` | Audio | 0..1 | `1` | Speech, on top of the master volume |
| `mute_when_unfocused` | Audio | true, false | `false` | Silence while another window has focus |
| `look_sensitivity` | Controls | 0.05..5 | `1` | How fast the mouse and right stick turn the view |
| `invert_look_y` | Controls | true, false | `false` | Pushing forward looks down |
| `stick_dead_zone` | Controls | 0..0.9 | `0.15` | How far a stick moves before it counts; raise it if a worn stick drifts |
| `toggle_hold` | Controls | true, false | `false` | Actions you'd hold, like sprint, toggle with one press instead |
| `ui_scale` | Accessibility | 0.75..2 | `1` | The menus' and HUD's size |
| `high_contrast` | Accessibility | true, false | `false` | Stronger colours and outlines in menus and the HUD |
| `subtitles` | Accessibility | true, false | `true` | Text for speech |
| `subtitle_scale` | Accessibility | 0.75..3 | `1` | The subtitles' size |
| `reduce_flashes` | Accessibility | true, false | `false` | Tone down full-screen flashes |
| `camera_shake` | Accessibility | 0..1 | `1` | How much the camera shakes; 0 turns it off |
| `field_of_view` | Camera | 0, or 50..120 | `0` | How wide the view is, in degrees from the top of the screen to the bottom; 0 for the game's own. The game may narrow the range |
| `language` | Language | a locale like en, fr or pt-BR | `(empty)` | The game's text; empty for the game's own default language |
